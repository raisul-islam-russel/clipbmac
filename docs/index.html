Clipboard history for Mac,
like Windows Win + V

ClipBMac is a free, open-source clipboard manager for macOS. Press one hotkey, see everything you copied, and paste it instantly.

Universal (Apple Silicon + Intel) · macOS 13+ · MIT licensed

Everything you copied, one hotkey away

Clipboard history

Text and images, last 50 items, with pinned items that never expire.

Instant paste

Pick an item and it is pasted into the app you were using.

Type to search

Open the panel and start typing to filter your history.

Keyboard first

↑↓ move, ⏎ paste, ⌘P pin, ⌘⌫ delete.

Private by design

No network, no account, no tracking. Password-manager items are ignored.

Native and tiny

Pure Swift and SwiftUI menu-bar app. No dependencies.

Install in 30 seconds

  1. Download ClipBMac.dmg from the latest release.
  2. Drag ClipBMac to Applications and open it.
  3. Press ⌘⇧V anywhere to open your clipboard history.

Or build from source:

git clone https://github.com/raisul-islam-russel/clipbmac.git
cd clipbmac && bash scripts/build.sh

Frequently asked questions

Is there a Windows Win+V equivalent for Mac?

macOS has no built-in clipboard history. ClipBMac gives you the same experience: one hotkey, a list of everything you copied, click to paste.

Does it work on Apple Silicon and Intel Macs?

Yes. The release is a universal binary and requires macOS 13 Ventura or newer.

Does ClipBMac send my clipboard anywhere?

No. It has no network access and stores history locally on your Mac.

Why does it need Accessibility permission?

Only to simulate ⌘V after you pick an item. You can deny it and paste manually.
